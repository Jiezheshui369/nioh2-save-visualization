# 0.7.13-dev 持续开发记录

2026-09-25。源码 0.7.13-dev，Android versionCode 713；解析器仍为 0.9.7。旧安装和旧测试包不覆盖。

## 社交分享

- 手机“分享当前配装”现在与电脑共用详细文字投影：固定八项能力顺序、装备等级、恩宠、全部已解析词条和数值。
- 深奥、单位待验证和未解析数值按详情页相同规则显示；不推算最终伤害，不把仓库绘卷写成当前佩戴。
- 自动生成的文字不带快照编号、指纹、金钱、精华或完整仓库。用户主动填写的标题/备注仍属于分享内容，不承诺自然语言匿名化。
- 图片旧“仁”印章改成 Nioh；标题/装备/恩宠按像素宽度省略，数值限宽，装备超过十一条时扩展画布不静默丢行。图片说明是摘要，完整词条用文字分享。
- 恩宠件数不写成套装触发档位，佩戴绘卷未识别状态始终明确。
- 原生取消转换为 AbortError，取消不等于发送成功，也不会改为下载；手机分享按钮在操作中禁用，快速重复点击亦受内部锁保护。
- 原生私有缓存文件名保留长名称后缀，清除路径字符和特殊相对路径、Windows 设备名。不立即删除已分享 URI，避免接收应用尚未读取完。

## 配装册

- 更新时间按实际时间比较，不按不同时区的字符串字典顺序排序。
- 导入/导出拒绝重复配装编号、空编号及无效更新时间，保留已有库不破坏性修复。
- 异步写入前独立复制约定字段，调用方稍后修改输入不改变待保存的配装。
- 旧版已经正常生成的 ISO 时间继续兼容；异常旧记录保留等待恢复，不当作空库。
