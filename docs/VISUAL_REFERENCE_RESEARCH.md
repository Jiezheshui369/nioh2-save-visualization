## 新增防具部位与物品原图

2026-09-21 已从 Fextralife Nioh 2 Wiki 的实际图片标签获取并逐张查看八张 PNG：头部、胸部、臂部、腿部、足部，以及八尺琼勾玉、护身符、百鬼绘卷。见 `design-assets/nioh2-equipment/README.md` 的来源页面、确切图片 URL、尺寸、SHA-256 与使用语义。

防具五图属于部位类别；八尺琼勾玉、护身符属于具体物品；绘卷图不表示某一张绘卷的佩戴状态。三者不可混淆。Wiki 同时有具体防具的图片，但在装备 ID 到图片的对应关系核对前，不用其他同类装备图片冒充。

检索中发现 Wiki 的旧 `Head_armor-icon.png` / `Chest_armor-icon.png` 引用已经失效，随后在防具套装页找到有效的 `Head-icon-nioh2-wiki-guide.png` 等新路径；因此不能仅凭搜索结果中出现 Image 文本判断素材存在。

## 首版原创重绘方向（武器方案已由上述要求替代）

- 装备槽：主武器、副武器、远程武器、头、胸、臂、腿、足、饰品、绘卷。
- 武器类型：刀、双刀、枪、斧、锁镰、大太刀、旋棍、手斧、薙刀镰、手甲等，以几何剪影重绘。
- 属性语义：体、心、勇、刚、武、技、忍、咒采用篆刻式汉字印记。
- 恩宠/套装：使用原创六边印章或环形纹章，不复制游戏内神祇徽记。
- 状态：离线、已导入、需更新、解析中、字段待研究使用通用原创线性图标。
