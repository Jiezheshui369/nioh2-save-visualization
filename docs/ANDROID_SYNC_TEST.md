# 0.7.4 电脑 → 安卓同步测试

本版不需要把 JSON 或游戏存档传到手机。只需在手机安装 APK，电脑解析，手机扫码接收。首次配对和更新需要同一可信 Wi-Fi；接收成功后，可以关电脑、离开 Wi-Fi，离线查看。

## 1. 准备安装

- 电脑程序：`D:\Android\apk-tests\Nioh2-PC-0.7.4\Start-Sync-Test.cmd`
- 安卓安装包：`D:\Android\apk-tests\nioh2-companion-0.7.4-dev-debug.apk`
- 把 APK 传到安卓手机并安装。可覆盖之前的同签名旧 测试版，先不要卸载旧版，以免丢失手机内的资料。如果提示签名不一致，停止安装并反馈，不要清除数据。
- 电脑与手机连接同一路由器的可信家庭网络，不使用访客 Wi-Fi。电脑有线连接同一路由器也可以。

## 2. 电脑导入并确认资料

1. 先关闭旧电脑程序，再双击 `Start-Sync-Test.cmd`，应出现独立应用窗口。启动失败时使用 `Start-Browser-Mode.cmd`，并保留该兼容模式的命令窗口。浏览器收藏不会自动复制到新窗口；电脑迁移步骤见 `WINDOWS-APP-TEST.md`。
2. 点击右上角“导入与同步”（或左侧“更多”），将你的 `SAVEDATA.BIN`（建议先用备份）拖入电脑页面的存档导入区，或点击选择存档。不要拖入整个文件夹、BACKUP.BIN 或 JSON。
3. 等待复制、解密和解析完成。该流程只读取选中的文件，解析独立副本，不写回游戏存档。
4. 核对等级、八项加点和一件当前武器。未验证的面板数值会显示未解析，不能据此认为整份存档读取失败。
5. 点击“更多 → 同步到手机”，再点击“开启同步并生成二维码”。Windows 若弹出防火墙提示，只允许专用网络，不要关闭防火墙。

## 3. 安卓扫码接收

1. 打开新安装的“存档伴侣”App，进入“更多”并点击“扫描电脑二维码”，允许相机权限。
2. 扫描电脑“更多 → 同步到手机”页面上的二维码。必须使用 App 内的扫码，不是微信或系统相机。
3. 点击“确认配对并同步”。看见已保存成功提示后，再核对与电脑相同的等级、加点和武器。
4. 无法使用相机时，可展开电脑“相机不可用？复制配对信息”，把完整配对文本填入 App 的“配对信息 / 手动输入”，再确认。此文本是临时凭据，不是档案文件，不要公开分享。

二维码十分钟内有效且只能使用一次；过期或已使用时，在电脑重新生成。多网卡电脑可选择另一电脑网卡地址后重新扫描。

## 4. 测试更新

1. 游戏保存完成后，在电脑重新拖入新存档（退出游戏后取备份更稳妥）。
2. 电脑核对新角色资料，进入“更多 → 同步到手机”，点击“发布当前角色到手机”。只刷新手机不会让电脑重新解析游戏存档。
3. 保持手机 App 在前台，等待约 15 秒，或点击“接收最新角色”。
4. 核对你刚改变的装备。失败时应保留之前已保存的角色，而不是清空资料。

## 5. 最重要的离线验收

1. 先确认手机显示同步保存成功。
2. 电脑点击“关闭同步并撤销配对”，然后退出电脑程序。
3. 手机打开飞行模式，从最近任务中完全关闭 App，再重新打开。
4. 应仍能查看已接收的角色、配装、仓库以及已经支持的装备属性。无法连接电脑的提示不应影响查看。
5. 恢复网络；电脑重新启动同步后，需要重新扫码。关闭同步、电脑程序重启或八小时会话到期都会使旧配对失效，手机离线资料不受影响。

## 排错与边界

- 找不到扫码按钮：可能仍打开旧 APK 或浏览器页面，请安装 0.7.4 APK 并打开 App。
- 连接失败：确认电脑窗口还在运行、已开启同步、两端同网、不是访客隔离网络。防火墙仅放行专用网络；本启动器电脑页面端口 13254、加密同步端口 13354。不要做公网端口转发。
- 证书校验失败：重新生成并扫描自己电脑的二维码，不绕过校验。
- 保存失败：保留旧档案，检查手机存储空间后重试；不要卸载或清除 App 数据。
- 默认独立窗口关闭时会退出电脑服务并撤销配对；浏览器兼容模式关闭标签页不等于停止服务，还需关闭对应命令窗口。
- 本版是本地同步测试版，不是公网云同步。外出可看最后保存的角色，但不能通过移动网络获取家中电脑的新存档。
- 原始存档不发送到手机；发送的是已解析并裁剪存档指纹的角色资料和已收藏配装。截图补录属性只有在当前角色档案已包含时才会发送，不会凭空从原存档自动解析出来。
- 当前 Windows 默认采用 WebView2 独立应用窗口；主界面沿用已确认的 Figma 风格；配装册和高级工具的细节布局仍待统一。

## 本轮已验证与待验收

0.7.4 开发测试覆盖前端 68 项、Python 62 项。打包程序的备份导入与加密同步联调结果见 `RELEASE_074.md`。Windows 独立窗口真实拖放、持久存储和系统对话框仍需桌面实测。

这些检查不等于安卓真机验收。还需在你的手机确认相机权限、扫码、持久保存、断网重启与系统分享。反馈时提供手机型号、安卓版本、具体步骤和错误提示，截图请遮住二维码及配对文本。
