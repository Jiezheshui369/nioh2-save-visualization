## 目标

做成支持多游戏扩展的存档资产化应用，《仁王2》是首个解析适配器，不把整个产品绑定为单一游戏工具。目标为电脑读取/解析、上传到自有服务器，手机登录同一账号后按用户点击同步某个游戏或全部已管理游戏；未点击时保留上次成功保存的离线数据，不自动替换。用户无需手动搬运 JSON。具体确认项与待定范围见 MULTI_GAME_SYNC_V1.md。

当前实现仍是仁王2解析、局域网扫码同步与离线存储；账号服务器同步和仁王3占位尚未实现。已确认规则见上文，不能把需求确认当成功能完成。本次私有 GitHub 上传应保留远端历史，只提交经过筛选的源码与文档。此前冻结包不随本次文档修改自动更新。

## V1 验收标准

- 玩家无需使用命令行即可在 Windows 应用窗口拖入 `SAVEDATA.BIN`。
- 原始文件始终只读；解密与解析只能发生在已校验的独立副本上。
- 桌面端能展示目前已验证的等级、加点、装备、恩宠、物品和绘卷数据，并明确标记研究中的字段。
- 桌面端发布隐私裁剪、版本化的分析结果，用户无需生成或传输 JSON 文件。
- 新目标：手机同账号访问服务器，提供单游戏和全部已管理游戏同步；新数据校验并持久化成功后才替换该游戏的离线版本，未点击不自动更新。现有扫码路径不代表云同步已完成。
- 多游戏数据与账号隔离；失败游戏保留旧版本，部分成功明确逐项展示；首次没有缓存时显示未同步，不能伪造数据。仁王2以外游戏不得冒用仁王2解析器。
- JSON 导入/导出仅作高级备份恢复，不是主业务流程。
- 手机端提供角色总览、配装详情、仓库和分享体验；仓库只设装备/物品主标签，不展示恩宠件数盘点。
- 品牌文字使用 `Nioh`；武器类别采用《仁王2》原图，并在 Figma Assets 中组件化、记录来源。
- 配装与仓库共用可展开的装备详情，展示已验证的具体词条数值；配装包含绘卷入口和未识别佩戴绘卷的状态。
- 角色页八项能力下展示人物详细属性，不重复主力装备；负重、敏捷、掉落率、妖怪化时间等未验证字段显示未解析。
- GitHub Release 不包含用户存档、解密副本、真实角色档案、Steam 凭据或本机绝对路径。
- Windows 与 iPhone 有可重复的构建、测试、版本升级和回滚说明，并保留 Android 兼容性。
