# 中文展示层

解析层继续保存英文原始名称，中文只在展示层通过 `src/localization.ts` 映射。这样既能与社区 ID 表、英文 Wiki 和调试日志对应，也不会因为翻译调整破坏历史快照兼容性。

功能验证阶段采用简体中文单语言界面，暂不提供语言切换。当前翻译表覆盖熟练度、稀有度、当前构筑的装备名称和词条、本地效果表中的 34 个恩宠，以及套装效果 `Onmyo Austerity`（阴阳严厉）。未知值在页面中显示为中文占位，不直接泄漏英文原始值。

装备与物品名称优先读取游戏自身 `archive_19` 的简体中文 PTRBUNDLE。`agent/tools/extract_official_localization.py` 只读对齐同构的英文与简体中文短文本记录，并对社区目录中的标点、大小写和唯一高置信拼写误差做保守归一化。当前生成的 `agent/data/official_zh_cn.json` 合并装备/物品包与茶器包，共覆盖 2,286 个物品编号；解析器会把一至三位短编号统一补齐为四位，再用于当前构筑、269 件装备仓库记录与堆叠物品列表。当前真实快照的 366 个堆叠物品槽中有 359 个命中中文名称（98.1%）。解析器只把命中的短名称写入快照的 `nameZh` 字段，不复制说明等长文本。

同一工具也从特殊效果文本包生成 `agent/data/official_effects_zh_cn.json`，目前覆盖 1,672 个词条编号。生成器可以把游戏内的 `%ls` 参数化模板与官方武器类别名安全组合，并用 `verified_effect_templates_zh_cn.json` 保存少量经本地语言包交叉验证的扁平化名称。快照中的 `effectIds`、`effectsZh` 与原始 `effects` 按位置对齐；未命中的未知编号仍使用中文占位。当前真实样本的 1,620 条装备与绘卷词条中有 1,562 条命中中文（96.4%），39 条绘卷名称均可用中文显示。

数值显示不等于数值编码已验证。0.9.7 解析器以 `effect_value_rules.json` 记录明确核对的 ID 编码；历史 `CAP` 上限推测仅保留为 `legacy-cap`，界面标注“单位待复核”，不计为可靠数值覆盖。深奥原值不是属性加成；尚未确认单位的妖力及档位保持未解析。`effectMagnitudes` 与 `effectValueDetails` 按词条位置对齐并保留原始 uint32，具体见 EFFECT_VALUE_CONTRACT.md。中文名称已命中不代表单位或生效状态已确认。

魂核在存档装备表中使用另一套编号，无法直接命中普通物品名目录。`agent/data/soul_core_zh_cn.json` 按存档中已经识别的英文妖怪名建立独立映射，并与公开的全魂核中文索引交叉核对；目录覆盖 78 个可匹配的 16 位魂核编号，当前样本的 44 种、107 个魂核记录已全部命中。映射只改变显示名称，不推断魂核等级、词条数值或锁定状态。

`agent/data/verified_variant_zh_cn.json` 仅收录“社区物品编号、英文变体名、官方本地语言包或公开简体中文资料”能够交叉确认的少量条目。目前包括鬼腕甲、发梳、黑/白扇子、白色勾玉和濑户瓢箪茶入（黄）。无法从编号和词条唯一判断的未知装备继续显示编号，不按外观或词条猜名称。

语言切换将在主要存档字段验证完成后实现。届时可直接复用解析层保留的稳定键，无需迁移历史快照。
