# 0.7.4 开发交付与验证记录

日期：2026-09-23。内部测试版，未上传 GitHub、未公开发布。

## 本轮交付

- Windows 默认 EXE 改为独立 WebView2 窗口；保留 Start-Browser-Mode.cmd 浏览器兼容入口。主界面沿用已确认的角色、配装、仓库、更多布局。
- 窗口使用固定本地 profile，不向网页暴露自定义文件系统 JS API。控制服务仅监听本机，用户主动开启的手机同步另走现有 TLS 服务。
- 窗口退出/创建失败均清理自己启动的服务和临时配对；占用默认端口时提示，不接管或关闭旧版本。
- 系统分享不可用时，配装文字保存为 TXT；原生手机分享通路保留。
- 同版本 Android 0.7.4-dev，versionCode 704，签名证书与 0.7.3 一致。

- 电脑：`D:\Android\apk-tests\Nioh2-PC-0.7.4\Start-Sync-Test.cmd`
- 手机：`D:\Android\apk-tests\nioh2-companion-0.7.4-dev-debug.apk`

- 两端完整同步测试：电脑目录内 `ANDROID-SYNC-TEST.md`

先关闭旧电脑程序，不要删除旧版本或存档。APK 可覆盖安装同签名版本，不要卸载或清除已有资料。首次配对/更新仍需同一可信网络；收到后可离线查看，不是公网云同步，也不要求把 JSON 传入手机。

浏览器与独立窗口存储隔离。原浏览器收藏需要通过电脑高级备份恢复迁入；已解析快照仍从原应用数据目录读取。请保留旧浏览器资料。Windows 程序文件在 D 盘，个人应用数据仍在 `%LOCALAPPDATA%\Nioh2SaveCompanion`，不自动搬迁或删除。
