# 0.7.11-dev 持续开发记录

2026-09-25，源码版本 0.7.11-dev，Android versionCode 711；解析器 0.9.7。旧安装、旧测试包保留。本记录仍在跟随开发更新，不是正式发布声明。

## 本轮改动

- 电脑发布后清除上一版的读取时间；返回发布时间、发布角色编号和版本。手机请求读取不代表手机保存成功。
- 展示角色或本页配装册变更后提示主动发布；重新进入页面时不假定配装已发布。状态无法确认时不显示旧二维码，可继续关闭同步。
- 手机恢复其他本地档案后清除版本去重；同一服务器版本能重新保存。组件卸载后迟到的网络响应不启动新保存。
- 角色、装备、绘卷、观察证据、配装册导出只投影已知字段，移除未知自动诊断字段及存档指纹；深复制数组及子记录。保留用户有意写入的名称/备注，这不是自然语言隐私清洗。
- 辅助数值字典、技能点计数、备份对比和效果类型深层校验；接受修改存档的数值，不加游戏合法性上限。
- 历史列表规范化旧服务的空值，拒绝坏字段/重复编号；下载和选中档案必须与请求编号一致。读旧缓存不进行破坏性修复。
- 刷新接口要求本机受信请求，旧局域网浏览器兼容入口必须提供显式令牌。开发代理只为同源回环页面转换来源，不放行外部 Host/Origin。
- 对 518 个已解包 DataTable 做有界、只读候选编号序列研究；输入哈希不变，无完整序列命中。单个整数命中不是字段语义证据，正式解析覆盖不变。

## 验收重点

1. 电脑读取角色 A 并主动发布，手机接收并断网重启，应显示 A。
2. 电脑读取角色 B 但不发布，页面应提示尚未发布，手机仍接收 A；明确发布 B 后再接收才更新。
3. 发布 B 后旧读取时间不沿用；手机显示成功前，电脑不能宣称手机已保存。
4. 电脑服务暂不可达时隐藏旧二维码；网络恢复后重新确认状态。关闭同步仍可操作；关闭失败有明确提示。
5. 手机通过高级备份恢复其他角色后，再接收原发布版本应恢复该版本，不误用之前的版本去重。
6. 修改配装册后主动发布；保存途中再次修改的内容应继续显示未发布提示。
7. 在 Mac 运行交接指南的测试及 Xcode 构建，再做 iPhone 权限/扫码/离线/分享验收。保留旧角色，禁止卸载应用来解决一般读取错误。
