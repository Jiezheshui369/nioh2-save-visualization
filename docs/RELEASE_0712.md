# 0.7.12-dev 持续开发记录

2026-09-25。源码 0.7.12-dev，Android versionCode 712，解析器 0.9.7。原始存档、D 盘旧安装和所有旧版本包保持不变。

## 改动

- 验证服务健康状态、能力标记、来源槽位、时间戳与本机 Steam 元数据；来源列表拒绝重复编号并只保留约定字段。旧版缺失能力标记按不可用处理。
- 健康检查从启动读取中独立出来，失败清除旧连接状态；新请求取消旧请求，迟到结果与卸载后结果不覆盖当前状态。
- 健康检查 15 秒、普通 API 读取 20 秒超时，包含读取响应体；取消时不提交迟到数据。超时后可使用已保存角色，授权失败不绕过认证。
- 读取新角色后的状态、来源和历史列表并行请求，避免累计等待。
- 诊断展示本机存档、当前档案和 Steam 本机缓存元数据，明确不是云端实时查询或手机持久化回执。断开不误报需升级，不启用旧槽位读取。
- 继续沿用已批准的角色/配装/仓库/更多布局，没有重做 Figma。

## 验证

- 320 项前端测试通过，网页和共享原生资源构建通过。
- 隔离浏览器使用空存档来源及合成档案：电脑服务停止后显示当前不可用、旧二维码隐藏；未访问真实存档。该检查不是 Windows WebView2 或 Android 真机验收。
- 断开后切回角色页仍可查看隔离合成档案（等级 120）；不是玩家真实档案。测试页与自有测试服务均已关闭。
- Python 130 项中 129 通过、1 因 Windows 符号链接权限跳过；Java 36 项配对与 16 项 DER 证书用例通过。
- 新 Windows 目录/ZIP 校验及实际 EXE 合成 TLS 联调通过：严格请求格式、刷新来源限制、再次发布状态、指纹/IP SAN、单次邀请、拉取与撤销。
- Android 构建、APK 签名验证通过，证书与此前测试版相同；不是生产签名版。
- 允许列表源码包需独立解压复验，最终结果以包旁 VERIFIED.md 为准。旧版本保留回退。
- 未在 Mac 编译 Swift/Xcode，未进行本版手机实测，未上传 GitHub。
