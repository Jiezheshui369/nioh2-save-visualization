# 技能标记候选研究（非正式解析）

2026-09-25，源码0.7.16-dev。工具 `agent.tools.scan_skill_markers` 只读显式指定的独立副本；正式解析器不导入它，也不把结果发给手机。

## 观察与有限假设

用户图例：圈为已习得，上升为未升满，无符号为未学。行内级别原文保留；无符号的“壹/1”不能当作一级已学，已习得奥义不代表已选择生效。

输入每条序列来自一个连续可见列表区域，不把不同截图未经证实地拼接。每段16–256条，最多12段；裁切/未知符号、缺失标签、重复段编号、统一符号的弱序列会拒绝。

工具检查以下有限假设，全部带 `verified:false`：

- 已学二值标记、升满二值标记；两者不能混为同一状态。
- 三种符号对应0/1/2的六种排列；不是已知的游戏编码。
- 等级文字表示当前等级、或上升符号文字表示下一等级，两种解释分别搜索；圈且无后缀暂按单级节点作假设，未知后缀不填0。这不构成实际技能等级表。
- 每种序列分别检查连续uint8/16/32（大小端）和1/2位打包（字节内两种位序、全部8种位相）。不假定自然对齐。

匹配只保留有界样例，计数与样例截断分别标记；共享候选检查预算有明确上限，超限时 `searchTruncated:true`，不能把部分搜索称为零匹配。无论找到多少候选，`newVerifiedFields` 始终为0。

## 本轮结果

私有观察选取4个完整可见区域，共96条半妖/忍术/阴阳术记录；这不是21张截图的全部逐项转录。两种现有副本各检查266种组合，无预算截断、输入哈希未变。

只有半妖第一页的“连续uint8已学标记”假设各命中两处；相邻半妖页与另外两页未同样命中。上下文是密集0/1字节区，不能据此确定技能ID、顺序、等级或活动奥义。地址与玩家内容仅在私有报告，不作为生产偏移常量。

负面结果不排除重排、每级独立节点、ID索引、非连续记录或其他编码。下一步需要能把一个具体技能变化与副本变化对应的独立证据，或可靠的技能ID/结构定义；不得擅自修改玩家技能或原存档来制造样本。现有截图不用重复发送。

## 可复现与交接

在项目根目录，用占位路径替换成自己明确选定的研究副本与观察文件：

```sh
python -m agent.tools.scan_skill_markers \
  --copy-root PRIVATE_COPY_ROOT \
  --decrypted-copy PRIVATE_COPY_ROOT/SAVEDATA.BIN \
  --observations PRIVATE_MARKER_OBSERVATIONS.json \
  --output-dir NEW_PRIVATE_OUTPUT_DIRECTORY
```

观察格式：`{"sequences":[{"id":"one-viewport","entries":[{"label":"技能名称","marker":"circle","rankText":"参"}]}]}`。示意中的一条记录不足以执行搜索；需要至少16条完整观察。`rankText`可省略，不自动补等级；`marker`只接受circle/upward/none。

报告目录必须全新且与输入分离；读取前后核对输入。源码包只包含通用工具和合成测试，不含截图、玩家序列、命中地址报告或存档。
