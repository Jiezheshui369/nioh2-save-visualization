# 0.7.10-dev · 电脑导入与失败恢复

2026-09-25。应用 0.7.10-dev／Android 710／解析器仍为 0.9.7。iOS 元数据 0.7.10/710，尚未在 Mac 编译，没有 IPA。保持已确认的四页布局，本轮不修改 Figma，不新增已验证人物字段。

## 本轮修复

- 电脑拖入、刷新、切换历史与备份恢复共用互斥锁，避免请求乱序切换角色；保存完成前不能再提交另一份文件。
- 导入失败区分网络、无效响应、超时与本地持久化失败，中文提示可直接重试。超时不声称服务器已取消；页面卸载后忽略迟到结果。
- 电脑分析和本机保存成功明确提示尚未发送到手机，仍需显式开启／更新发布并在手机接收。
- 刷新有四分钟等待上限，保留原角色；缓存尝试结束后才释放读取操作，防止后台缓存晚到覆盖后续导入。
- 导入、同步控制、刷新共同校验请求长度：拒绝重复、负数、非法格式、超限与任何分块传输头，截断／传输超时不启动解析。桌面控制拒绝重复 Host、Origin 和控制标记。
- 可选文件修改时间无效不影响正常导入。成功响应前清理本次临时上传副本；永久保护副本继续保留。
- 切换来源解析失败保留原选中来源；主存档或备份副本在解析期间被其他进程改动时不发布结果，不只记录一个失败布尔值。
- React／前端技能用于异步互斥、清理和错误反馈，没有重设计页面。

## 验收重点

1. 在新电脑窗口拖入自己的 SAVEDATA.BIN，分析时刷新和历史选择不可用；成功后确认角色正确。
2. 点击开启或更新手机同步，再在 APK 接收。看到电脑成功不代表手机已经更新。
3. 手机接收成功后断开 Wi-Fi，关闭电脑并重启手机应用，确认角色及配装仍可查看。
4. 错误文件应提示拒绝且保留旧角色；测试不需要改动游戏原文件，不需要填满设备存储。
5. 若等待超时，稍后重试；服务器仍解析时应提示已有任务，不能并发启动第二次。
6. 解析尚未验证的最终面板字段继续显示未解析，不会用截图观察值填充自动解析结果。
