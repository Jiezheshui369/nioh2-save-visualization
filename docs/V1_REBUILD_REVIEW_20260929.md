## 1. 结论与交付范围

不需要推倒重做。已有的仁王2解析器、已认可的角色/配装/仓库界面、离线能力和原生工程可以保留；主要重构的是数据归属和同步流程，主要新增的是账号、服务器、多游戏管理与电脑采集任务。

本周首发范围已确认：**Windows + Android 云同步内测版**，按小规模受邀账号设计；仁王2提供真实解析与展示，平台支持不同游戏适配器接入。不能把这个版本称为“所有游戏通用解析版”或“仁王2人物属性全解析版”。完整解析要求保留为后续任务，不据此宣称已经完成。

目标体验：玩家授权管理某个游戏 → 电脑读取稳定的存档副本并解析 → 上传同账号服务器 → 手机主动点击“同步此游戏”或“同步全部” → 成功保存后离线查看。**电脑上传成功，不代表手机已经同步；手机不点击，就不替换原有离线数据。**

### 本周实施范围（核心已确认，细项按下文约束）

- Windows：登录、管理仁王2存档位置、手动上传、可选的自动采集上传、上传结果与失败重试。自动上传按游戏单独开启，默认关闭；程序运行且联网才可执行。
- 服务端：受邀账号登录、设备会话、账号数据隔离、游戏/存档身份、不可变快照、版本列表、最新版本指针、容量和请求限制。
- Android：登录、游戏列表、单游戏同步、全部已管理游戏同步、离线浏览、逐项结果及最后成功同步时间。
- 仁王2：沿用已验证解析和现有四个主要页面；未解析项如实标记。体力/精力/妖力仍只显示最大值。
- 通用适配器契约、独立游戏命名空间；用第二个合成适配器验证隔离和“全部同步”。合成测试不等于支持第二款真实游戏。
- 新安装包、源码交接、测试记录、部署和回滚说明；仅本地交付及经另行授权的测试服务器部署，不自动上传 GitHub 或发布商店。

### 本周无法无条件承诺的部分

- **仁王2剩余 37 项最终面板及 116 条聚合特殊效果**尚未完成。截图转录、来源候选和装备词条解码不能充当最终字段已解析。研究耗时不确定，不能用估算公式或硬编码截图赶工。
- **第二款真实游戏解析**明确不纳入本周；“仁王3”仅作为 UI 占位，不代表获得存档样本或已支持该游戏。
- **iOS 编译和真机验收**需要 Mac/Xcode 和测试设备；现有工程保留，但当前 Windows 环境不能证明其可交付。商店审核不在本周承诺内。
- 原始存档云备份、下载恢复到游戏、多电脑自动合并、远程唤醒电脑、Steam 云存档直连、公开注册/收费/公开社区，均不默认包含。

如果“本周完成”同时包含云平台、全部人物属性、第二款真实游戏和 iOS 真机版，当前没有足够依据给出可信的周五完成承诺。需要在**范围和日期之间明确取舍**，不能把未完成部分从需求中悄悄删除。

## 3. 新增与重构工作

### A. 数据与适配器边界

- 通用层包括账号、设备、游戏、存档身份、快照 ID、服务端修订号、采集时间、解析器版本、数据结构版本；玩家身份由服务端会话确定，不能相信请求自行填写的账号 ID。
- 游戏适配器负责文件识别、稳定读取所需文件集合、解析和专属展示。不能把仁王2的判断规则应用到所有游戏。
- 同游戏多个存档保留不同身份，不因显示名称相同而合并。第一版多电脑对同一存档出现分支时保留版本、提示选择，不以电脑时钟“最后写入”覆盖。
- 服务器只保存选定的分析快照（本周提案）；原始存档备份若获批准，应作为独立类型、权限和容量策略，不能暗中跟随上传。

### B. 账号与服务端

- 优先小规模受邀账号，避免把公开注册、邮件找回、社交登录同时塞进本周范围；具体认证方案在实施前确定，密码如存在不得明文保存。
- HTTPS、可撤销的设备会话、过期会话处理；任何快照读取、写入、历史列表都检查所属账号，不能只保护登录入口。
- 上传幂等、大小限制、内容结构与版本校验、单账号配额、速率限制；失败上传不能破坏旧快照和最新指针。
- 保留版本以便恢复；建议内测每存档保留最近 10 份成功快照、账号配额先可配置，具体数值待审核。删除旧版本的策略不能默认等于允许删除玩家原始存档。
- 最小运行能力：配置与密钥分离、日志脱敏、健康检查、数据库迁移、备份与恢复实测、部署回滚。

### C. 电脑采集与上传

- 只监控玩家明确添加的游戏/文件，不扫描上传整台电脑。提供手动“采集并上传”，作为自动任务失败时的可靠入口。
- 自动模式建议采用“文件变化提示 + 稳定性校验”，游戏退出信号仅作辅助。退出不等于文件已写完；云客户端也可能在退出后更新本地文件。
- 适配器校验所需文件集合，复制前后核对一致性，再解析独立副本；连续变化、缺文件或失败时不上传半成品。
- 对重复通知去重；断网排队、有界重试、明确待上传状态。任务恢复时确认账号和内容身份，不能把旧账号任务发给新账号。
- 不需要每次开发或运行都提升管理员权限；若某目录不可读，提示选择允许读取的位置，不通过管理员运行掩盖权限问题。

### D. 手机同步与离线

- “同步此游戏/全部”只拉取服务器已经上传的数据，不远程强制电脑重新解析。界面区分采集时间、服务器接收时间、手机保存时间。
- 全部同步开始时固定游戏清单，逐项完成与报告；一个游戏失败不清空其他游戏数据，也不把部分成功提示成全部成功。
- 下载、校验、原子保存、切换展示按顺序执行；旧响应、取消任务、退出账号或离开页面不能迟到覆盖新状态。
- 未点击时，即使重启应用或网络恢复，也不替换离线快照。首次没有缓存显示“尚未同步”；断网或登录过期仍可按本地访问策略查看已保存内容。
- 换账号不能看到上一账号资料。第一版建议退出即关闭该账号缓存访问；重新验证账号后才解锁其缓存，是否提供额外本地锁待后续评估。
- 旧 0.7 缓存先备份，首次迁移由用户确认归属，不把历史资料自动上传或归到当前登录账号；迁移失败可回退旧版。
