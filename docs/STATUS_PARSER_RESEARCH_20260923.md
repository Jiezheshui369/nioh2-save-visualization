# 全量状态解析：本轮证据与未完成项

## 需求与样本

用户反馈 0.7.4 检测正常，要求解析此前截图的所有状态数据；确认截图后没有更换装备。本轮不改 UI 或 Figma，以自动解析为目标，不将截图转录变成解析结果。

应用最新结构化快照与最新解密副本，经只读哈希核对，和工作区既有 2026-09-19 研究副本内容一致，因此没有重新读取或解密原始游戏存档。该确认只涉及样本相同，不证明游戏当前内存或尚未保存状态相同。

## 逐项核对结果

总计 164 项，来自 48 项面板记录与 116 条去重特殊效果：

| 类别 | 数量 | 结论 |
|---|---:|---|
| 已有直接读取字段且与截图一致 | 11 | 等级、八项加点、精华、金钱；本轮不是新增解析 |
| 最终面板值待验证 | 37 | 体力、精力、攻防、重量、敏捷、抗性、术力/容量等 |
| 找到同名装备/绘卷/候选魂核来源 | 58 | 仅是贡献来源候选，不代表已还原角色总效果 |
| 未找到同名来源 | 58 | 还需技能、守护灵、套装、称号、武家及名称映射研究 |

原来的装备/绘卷匹配只有 51 项；加入三个明确标为“未确认魂核副本”的研究地址后增加至 58 项。没有把这七项增加写成新解析成功率。

完整 164 行的私有报告位于 `.local/status-research-20260923-final/状态解析核对.md`，原始证据在同目录 `status-audit.json`。文件不放入 public、dist、安装包或公共素材目录。

## 已修正的解析器错误

解析器源码版本更新为 0.9.6；本轮尚未重新打包或覆盖 D 盘安装版，已安装的 0.7.4 不会自动更新。

| 效果 ID | 语义 | 修正 |
|---|---|---|
| 91A6 | 装备重量上限 | 原始值按十分之一重量显示，而不是整数 |
| 164A | 瞄准远距离武器时移动速度 | 原始值按十分之一百分点显示，补上百分号 |
| 9158 | 妖念量表增加量 | 原始值按十分之一百分点显示，补上百分号 |

原因是原实现用社区表 `CAP` 是否含小数点判断单位。但 CAP 是参考上限，不是编码规范；整数上限同样可能对应小数或百分比。本轮只对已核对的三个 ID 使用明确规则，不把所有 CAP=1 或 CAP=2 的项目一起改写。

源码仍有旧的 CAP 启发式路径，不能宣称其余所有数字均经过实机校准。尤其“妖力”等小数固定值和“深奥”能力门槛应进一步类型化；深奥记录的 150 不能直接理解为能力加成 +150。档位、无数值效果也不能用 CAP 字符串代替存档实际效果。

## 魂核与绘卷线索

在当前副本中找到三个 0x90 字节间隔的魂核候选记录：

- `0x1D02E0`：独脚踏鞴，含对火敌人的妖怪技伤害、装备品掉落率、混沌敌人妖力、妖力。
- `0x1D0370`：大岳丸，含妖力、混沌敌人妖力、妖念量表、妖念发动时精力伤害。
- `0x1D0400`：祸津武士，含武技伤害、累积伤害妖力、妖力、妖怪技精力上限伤害、赋予雷状态精华量表。

这些候选能解释截图中的部分数值。与此同时，`0x1E7358` 一带存在内容不同的魂核副本，`0x214510` 一带又有相同效果的重复记录。因此固定取第一个同名魂核、把所有副本相加或假定这些就是当前主守护灵，都会造成错误。候选地址仅通过研究工具参数使用，没有接入生产解析器的佩戴槽位。

绘卷库存 recordIndex 39 同时包含截图中的四项深奥、妖念量表和畜生道词条，是明确候选。它的妖念量表数值与候选大岳丸词条相加吻合截图，但这仍不是通用的“当前佩戴绘卷索引”解码，不能硬编码成第 39 张。

## 最终面板不是一次搜索数字就能得到

对截图面板尝试 uint32、float32、float64 和小数十分位编码。部分值没有精确匹配，部分有多个匹配；精力的 uint32 匹配还未对齐。研究工具保留次数、对齐数和受限地址示例，并一律标记未验证。

这不证明字段不存在，也不证明一定全部由运行时计算；只是目前不能将搜索命中直接当字段。不能把 37 项最终面板值简单设为装备词条之和：需要基础成长、爱用度、改造、技能、守护灵/魂核、套装、称号、武家等完整贡献与适用条件。

## 测试与安全

- Python 77 项测试通过，其中本轮新增 15 项；覆盖单位修正、直接值不一致、候选不升格为已解析值、备用武器不无条件相加、绘卷库存不当佩戴、扁平值与百分比不合并、输出隐私字段排除等。
- 工作区 13 份既有解密副本重新解析通过，只有 2 个不同内容哈希，不能冒充 13 种独立配装样本。涉及三个修正 ID 的记录均通过单位断言；输入前后哈希不变。
- 40 份历史结构化快照审计通过；这不是 40 份独立状态对照。
- 原始存档、应用现有快照和用户浏览器资料均未改写。报告另存；研究工具拒绝覆盖已有输出目录。

## 下一步所需最小证据
