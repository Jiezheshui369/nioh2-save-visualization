## 实际解析改动

- 新截图与两份已有独立副本核对三枚魂核的13条词条、12个不同ID。三项妖力十分之一固定值、六项百分比十分之一编码、三个稀疏档位组合进入正式词条解析。
- 档位只确认3961/raw13→AA、9AD2/raw13→AA、24E8/raw8→B+。邻近原值不推断，不用CAP参考上限代替；grade/verified-id与numeric明确区分。
- 前端核对已验证的ID、原值与显示值一致后才计入覆盖率。旧妖力错误百分比不恢复；不一致档位/数值显示未解析，原档案不改写。
- 已确认十分之一编码使用整数格式化，uint32大值和0不损失精度，不按正常游戏上限裁剪。
- 新增Python→TypeScript→档案导出跨语言验证，使用完全合成的内存记录，不依赖个人副本。

这些不是最终人物面板新增字段：164项核对仍为11直接匹配、37最终面板待验证、58总效果仅有来源候选、58未找到同名来源。37项最终面板及116条总效果尚未完成，不能称“全解析版”。
