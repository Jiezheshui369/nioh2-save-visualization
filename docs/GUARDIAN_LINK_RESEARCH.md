# 守护灵／魂核记录关联研究

2026-09-25，研究工具，不属于 0.9.7 正式解析字段。

0.7.16源码接续：新增主副守护灵与三枚“凭附中”魂核截图，已确认本次配装的名称/显示值与候选结构相符；对应词条单位/档位进入0.9.9解码。但两份副本中绑定未变，仍不能把该单配装名称关联推广为跨角色选择器。佩戴绘卷截图对应已有库存候选，选择指针未解码。下文的结构与未验证边界仍有效。

## 已完成的结构检查

`agent/tools/trace_equipment_links.py` 对完整库存记录做有界字节追踪，分别检查候选标识片段和完整词条块；匹配后还要核对物品 ID 及记录前 132 字节。相同词条出现在不同区域，不表示都是当前生效装备。

本机两种不同哈希的角色副本都出现同一候选结构：37 个非零、互异的表内编号，三条非空魂核副本与其后库存索引指向的完整记录体一致，其余 108 个槽为物品 ID=0 且索引为库存容量的空槽候选。空记录仍有 FF 与默认值，不能用“整条记录全零”判断。

研究布局：候选表起点 `0x1CC708`，每行 `0x1D0` 字节；行内两项 uint32 头字段、三条 `0x90` 记录、八字节填充、三个 uint32 库存索引、四字节填充。表前 `0x1CC6FC` 和 `0x1CC700` 的两个 uint32 值各匹配唯一表内编号。

这些是当前样本下的**候选布局**，不是跨版本契约。生产解析器不读取这些地址。具体编号、玩家名称和记录内容只保留在私有研究报告。

## 仍不能下结论的部分

- 两个选择编号是否分别是主／副守护灵，以及游戏中当前活动的顺序。
- 表内编号与守护灵名称的对应关系。
- 同一魂核在其他区域的副本是否是历史配装或其他状态。
- 当前佩戴绘卷：词条可定位库存候选，但没有证据证明选择字段，不能以四深奥相符直接标为佩戴。
- 两种不同内容的副本没有改变这些绑定，因此只验证结构稳定，不能代替绑定变化的独立语义验证。

工具输出始终带 `selectionVerified: false`。单元测试覆盖越界、重复编号、错误索引、复制体不一致、空槽默认值和选择编号不唯一。截图状态研究现在也区分来源编码的 verified-id / legacy-cap / not-decoded；来源编码正确仍不表示人物总效果已解析。
# 后续静态资源调查注意

0.7.14 接续：新增显式 `--id-order permutation`，在块内寻找任意排列、固定步长的完整编号集合，仍限 16/32 位小端对齐和步长 4096。以稀少编号锚定，位置/输出/探测均有限额，截断分别标记；合成随机数据与穷举结果交叉验证。实际只读 518 个容器、7252 个块宽度组合、657347 次值探测，零完整匹配，无不支持容器、位置/探测/结果截断；输入/证据哈希不变。只排除该范围固定步长排列，不排除多层索引、变长表、压缩或编号变换，不增加正式字段。私有报告 `.local/datatable-ids-0714-permutation` 不迁移。

0.7.13 接续：确认存档候选表编号并非按数值排列，工具增加显式 `--id-order ascending` / `descending` 两种有限假设。分别只读检查同一 518 个容器，两轮均无完整序列命中；无不支持容器、搜索位置或结果截断，输入和编号证据哈希保持一致。结合此前原记录顺序仅排除了这三种等步长序列排列，不涵盖任意重排、间接索引、压缩或变换编号。没有新增守护灵名称/活动槽或最终面板字段。报告只在私有 `.local/datatable-ids-0713-ascending` 和 `descending`，不进入安装包或源码交接。

0.7.11 接续：新增 `agent.tools.inspect_datatable_ids`，只读检查显式指定的已解包目录，校验目录偏移/长度并逐块搜索 37 个候选编号的有序等步长序列。对已有 ARCHIVE_00 的 518 个 DataTable 容器执行 16/32 位小端对齐、步长不超过 4096 字节的搜索，全部容器通过边界检查，未找到完整序列；输入前后哈希一致，无搜索位置截断。部分块包含全部 37 个独立整数，但不按目标序列排列，不能因此称为守护灵表。该负面结果只排除本次搜索形式，不能排除重排、压缩、位打包、变换编号或其他资源文件；没有新增正式解析字段。报告保留在私有 `.local`，源码交接只带工具和合成测试，不带解包数据。

2026-09-25 另核对 [Cethleann 的 DataTable 实现](https://github.com/neptuwunium/Cethleann/blob/develop/Cethleann/Tables/DataTable.cs)：该名称指一个按偏移和长度分块的通用容器，不保证内容是人物参数。已有 ARCHIVE_00 解包中的七分块文件不能仅凭扩展名当作守护灵配置表。当前未建立文本编号、容器字段与存档候选守护灵编号的可靠映射；单个整数相同不是映射证据，不能依此赋予守护灵名称或自动效果。
