## 与静态稿的必要差别

- 系统时间、电池、底部手势条由安卓系统提供，不绘制假的 09:41 或电量图标。保留安全区并采用暗色系统栏。
- 字体采用 Inter（设备存在时）和系统中文字体回退，不额外依赖在线字体。
- 触控按钮至少 44px；长名称可换行，内容滚动而非裁切。不同尺寸下保持四列能力卡片等宽。
- 不使用设计稿中的示例名称、套装触发档位和伤害加成；配装页只统计实际记录件数，并明确不是触发档位。
- 原始数据未给出角色名称，因此角色名称仍为“无名武士”。截图补录仅在快照 ID 匹配时展示，不冒充自动解析。
- 绘卷佩戴关系尚未识别，配装入口明确提示，绝不拿第一张绘卷当作已装备。
- 当前解析器武器类型只有 Weapon；仅按明确名称词语进行展示分类，不能确认的保留“未分类武器”。大炮和通用饰品缺少已核对图标，保留文字回退，不冒充特定道具。
- 更多页承接已有同步/高级备份功能，使用同一配色与尺寸令牌。同步面板保持挂载，切换主页面不停止前台轮询。
- 原有收藏配装册保留功能与旧布局，是后续视觉统一项；本次不宣称全产品逐像素一致。

## 图标

武器/防具/指定饰品/绘卷使用此前已核对并入 Figma Assets 的本地 PNG，Vite 将其纳入离线资源。菜单、搜索、提示、精华和金钱图标为 Figma MCP 导出的原 SVG，见 src/assets/figma/README.md。精华/金钱仍是设计稿奖杯/钱包符号，不是新找到的游戏原图；原图搜索任务按用户意见暂缓。

这些游戏图片的公开再分发许可尚未确认；当前只制作内部测试 APK，未上传 GitHub 或商店。

重点检查：角色页卡片、配装点击完整属性、仓库筛选及物品、绘卷入口、底部滚动、更多中的同步，以及断网重启。
