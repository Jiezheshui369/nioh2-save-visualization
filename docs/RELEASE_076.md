## 如何验收这轮修正

1. 关闭旧电脑程序，打开新包的 Start-Sync-Test.cmd；不要删除或覆盖旧应用数据。
2. 在电脑重新导入原存档，程序会生成独立副本再解析；仅刷新旧快照不会重解析。检查解析器版本为 0.9.7。
3. 在绘卷中打开含深奥的记录，应显示“条件词条（非数值加成）”，不能把 150 显示为属性加成。尚不能自动识别当前佩戴绘卷。
4. 已知妖力来源显示“单位未解析”；未解档位显示“档位未解析”；目录标记非数值效果显示“非数值词条”。这些标签不表示生效状态。
5. 电脑主动发布；手机同一可信 Wi-Fi 扫码接收。Android 用新 APK 覆盖安装，不先卸载或清数据。不要求在手机导入 JSON。
6. 手机打开配装／仓库详情、分享文字，标签应和电脑一致。断网并重启后仍能查看这次接收的资料。
