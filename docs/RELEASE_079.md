# 0.7.9-dev · 离线角色可靠性

2026-09-25。应用 0.7.9-dev／Android 709／解析器 0.9.7。iOS 仅更新元数据 0.7.9/709，尚未在 Mac 编译，无 IPA。不覆盖旧安装、旧测试包，不操作原始存档，不公开 GitHub。

## 修复

- “保存最近 20 份”只写历史，不再把每份下载依次设为当前角色，避免离线启动变成最旧记录。
- 显式历史下载遇到数据库失败立即报错；可选实时浏览缓存仍允许失败而不阻塞在线查看。
- 手机启动必须区分空库、存储故障和损坏记录；显示保留原数据的错误与重试入口，不要求卸载或清数据。
- 清除缓存等待事务完成才显示成功；失败保留错误提示。下载与清除互斥，并明确不清除独立配装册、不修改游戏存档。
- 修复索引异步写入异常未被捕获、读取失败未关闭连接、超限旧历史留下孤立记录；来源元数据只用于匹配的角色。
- 延续 0.7.8 的事务配装册与部分同步恢复，不重新设计已批准页面；React／前端技能仅用于异常提示与操作状态。

## 重点验收

1. 保留旧安装和手机资料，不卸载、不清数据；独立运行新版。
2. 收藏两套不同配装，电脑发布，手机扫码接收，然后关闭电脑／断网重启手机查看。
3. 在电脑高级安全工具保存历史后离线重开，当前角色应仍是之前正在查看的角色，不应切成最旧历史。
4. 存储错误已在合成测试库覆盖，不要求人为填满手机。若遇到读取失败，优先点击重试，不清空应用。
5. 解析未完成的字段仍显示未解析；本轮没有扩大最终人物数值的已验证覆盖。
