# 仁王 2 防具、饰品与绘卷图标

核对日期：2026-09-21。八张 PNG 均从 Nioh 2 Wiki 页面的实际 `img src` 获取，保留原文件，无重绘、裁切或改色；已逐张打开查看。

## 使用语义

- `head/body/arms/legs/feet`：五种防具部位的**类别图标**，不是该行具体装备的外观图。
- `yasakani-magatama/omamori`：八尺琼勾玉、护身符的**具体物品图片**，不得当作所有饰品的通用图标。
- `demon-parade-scroll`：绘卷类别展示图，不证明具体绘卷的外观、稀有度或佩戴关系。
- 防具类别筛选可用 body 图代表防具，具体部位列表用对应部位；通用饰品筛选仍使用文字。
- 页面每行只使用一个固定图标槽，实例以等比 FIT 显示，不追加第二套图标。
