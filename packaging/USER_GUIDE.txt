仁王2 存档伴侣 0.7.4 · 内部测试版
=====================================

主要流程：电脑导入分析 → 安卓 App 扫码接收 → 手机离线查看。
不需要向手机传 JSON。完整测试步骤见同目录 ANDROID-SYNC-TEST.md。

启动电脑
--------
先关闭旧电脑程序，再双击 Start-Sync-Test.cmd 或“仁王2存档伴侣.exe”，默认打开独立应用窗口。关闭窗口会停止本机服务并撤销临时手机配对，不删除手机离线资料。
窗口启动失败时使用 Start-Browser-Mode.cmd，它会打开本机浏览器；兼容模式须保留命令窗口，关闭它或按 Ctrl+C 停止程序。不要使用旧 Start-Phone-Mode.cmd 测试新 APK；旧脚本只用于历史浏览器局域网模式。

导入与同步
----------
点击“导入与同步”（或左侧“更多”），将 SAVEDATA.BIN 拖入导入区，或点击选择存档。程序只读取所选文件，建立独立副本后解密解析，不写回游戏存档。
核对角色后，进入“更多”下方“同步到手机”，点击“开启同步并生成二维码”。
安卓手机覆盖安装同签名 0.7.4 APK，不卸载旧版、不清除资料。与电脑连接同一可信 Wi-Fi。在 App “更多”中点击“扫描电脑二维码”，扫描后点击“确认配对并同步”。
Windows 防火墙若询问，只允许专用网络，不要关闭防火墙，不要做公网端口转发。
接收并保存成功后，手机可关网、离开电脑，重新打开 App 查看。

更新与撤销
----------
游戏保存后，在电脑重新导入并点击“发布当前角色到手机”。手机前台每 15 秒接收，或点击“接收最新角色”。
二维码单次使用、十分钟有效；配对最长八小时。电脑关闭同步或程序重启后需重新扫码。
关闭同步会撤销全部设备凭据，但不会删除手机已有的离线资料。
本版不是公网云同步，离家后查看的是上次已保存的资料。

隐私与本地数据
--------------
原始存档不会发送给手机；仅发送角色、装备、物品及收藏配装等结构化资料，移除存档哈希。
不要公开分享二维码和配对文本。不需要 Steam 密码。
电脑应用数据默认位于 %LOCALAPPDATA%\Nioh2SaveCompanion。
手机卸载应用或清除应用数据可能删除离线资料，请谨慎操作；高级 JSON 导入导出仅作为备份恢复工具。

当前限制
--------
Windows 新窗口与原浏览器的前端存储不互通：浏览器中收藏的配装请先在高级工具导出备份，再在新窗口恢复。原有解析快照和存档副本保留。此项仅用于电脑迁移，不是手机主流程。详见 WINDOWS-APP-TEST.md。
主界面与手机统一为角色、配装、仓库、更多；配装册和高级工具还保留旧组件布局。
任务、技能树、收集、武家等尚未验证字段会标明未解析。截图补录面板值不是自动解析结果。
测试包通过编译和自动化测试；独立窗口真实拖放、持久存储、保存对话框，以及安卓真机扫码、断网重启及分享仍需要用户验收。

本项目与 Koei Tecmo、Team Ninja 或 Valve 无隶属关系。
